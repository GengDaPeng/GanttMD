## 1. 文档定位

本文档是 `jwxt` 项目的模块规格主线总控看板，用于管理模块规格推进、模块代理分工、模块质量门、跨域依赖关闭和需要反馈系统总调度的事项。

本文档只管理模块规格主线：

- 各模块当前进度。
- 模块代理任务分发。
- 模块规格质量门。
- 跨域依赖关闭状态。
- 需要反馈系统总调度的稳定事项。

本文档不管理：

- 后端工程骨架怎么搭。
- 前端页面怎么设计。
- 设备 SDK 怎么接。
- V1 总体验收怎么排。
- 系统级 M0-M8 里程碑。

与系统总调度的边界：

- 系统总调度负责四大主线、全局里程碑、质量门和跨主线阻塞。
- 模块开发总控负责模块内部任务分发、模块规格推进顺序、模块代理协调和模块审查节奏。
- 后端工程、数据库迁移、前端工程、设备接入、V1 验收只在本文登记为“需反馈系统总调度”，不在本文展开方案。

## 2. 状态标记

本文统一使用以下状态：

```text
[x] 已完成
[~] 进行中
[>] 下一步优先做
[!] 阻塞或高风险
[ ] 未开始
[-] 暂缓
```

状态使用规则：

- 已完成项只改为 `[x]`，不得删除历史路径。
- 新增说明写在对应项下方，格式为 `> 说明：...`。
- 状态变化必须改 checkbox，不只改自然语言。
- 取消或延后的任务用 `[-]`，并写明原因。
- 不把系统总调度事项写成模块代理任务。
