# Acme Notes 产品说明

Acme Notes 是一个虚构的团队笔记产品，用于展示 GanttMD 如何表达真实软件项目的任务状态。

## MVP 目标

- 团队成员可以创建、编辑和保存 Markdown 笔记。
- 编辑器能展示保存状态，并在离线或冲突时给出清晰提示。
- 团队可以生成只读分享链接。
- 发布前必须有基本用户指南和回归测试清单。

## 非目标

- 首版不支持旧笔记格式导入。
- 首版不提供企业级权限模型。
- 首版不提供托管版部署服务。

## 用户路径

1. 用户打开笔记列表。
2. 用户创建或打开一篇笔记。
3. 用户编辑标题和正文。
4. 系统自动保存草稿。
5. 网络异常时，页面提示保存状态和重试方式。
6. 用户可以生成只读分享链接。
