# 安装、更新、卸载与迁移

本文面向使用 GanttMD 的业务项目。目标是让项目只保存 `.ganttmd/` 数据，工具本身通过安装式 CLI 提供。

## 基本边界

- 项目数据只在使用方项目的 `.ganttmd/` 中。
- `ganttmd` 工具安装在项目外。
- 更新或卸载工具不应删除、覆盖或迁移项目里的 `.ganttmd/`。
- 会写项目文件的命令必须显式执行，例如 `ganttmd init`、`ganttmd migrate --apply`。
- 本地看板 `ganttmd start` 是只读聚合，不直接改任务文件。

## 安装

本仓库本地开发时：

```bash
cd /path/to/GanttMD
npm install -g .
```

发布到 npm 后：

```bash
npm install -g ganttmd
```

安装后确认：

```bash
ganttmd --version
ganttmd --help
```

## 更新

本仓库本地开发时：

```bash
cd /path/to/GanttMD
git pull
npm install -g .
```

发布到 npm 后：

```bash
npm update -g ganttmd
```

更新工具后，对每个使用方项目执行：

```bash
cd /path/to/your-project
ganttmd doctor
ganttmd migrate
ganttmd validate
```

如果 `ganttmd doctor` 提示 schema 落后，先运行 dry-run：

```bash
ganttmd migrate
```

确认计划无误后再显式写入：

```bash
ganttmd migrate --apply
ganttmd doctor
ganttmd validate
```

`migrate --apply` 会在 `.ganttmd/.backup/` 下保存被改文件的备份。
建议把 `.ganttmd/.backup/` 加入使用方项目的 `.gitignore`，迁移备份用于本地回滚，不应提交到 Git。

## 卸载

卸载工具前可以先停止本地服务：

```bash
ganttmd stop
```

本地开发安装版：

```bash
npm uninstall -g ganttmd
```

如果是从本仓库 `npm install -g .` 安装，npm 仍按 package 名称卸载：

```bash
npm uninstall -g ganttmd
```

卸载不会删除使用方项目中的 `.ganttmd/`。如果只是从本机看板移除项目登记，不删除项目数据：

```bash
ganttmd project remove <project-id-or-path>
```

## 迁移到真实项目

以真实业务项目为例，建议按这个顺序：

1. 在 GanttMD 项目里确认样例数据和工具能力已经通过测试。
2. 在真实项目根目录创建或复制 `.ganttmd/` 数据。
3. 把 `docs/Agent协作规则模板.md` 的必要规则合并到真实项目 `AGENTS.md`。
4. 在真实项目根目录运行：

```bash
ganttmd doctor
ganttmd migrate
ganttmd validate
```

5. 若 `migrate` 有计划，先审查 diff，再执行：

```bash
ganttmd migrate --apply
ganttmd doctor
ganttmd validate
```

6. 登记并打开本地看板：

```bash
ganttmd project add . --id <project-id> --name <project-name>
ganttmd start
```

7. 在页面确认：

- 项目标题、里程碑、任务数正确。
- 执行视角默认打开。
- 可执行、进行中、阻塞、已完成、已取消、已归档筛选可用。
- 任务抽屉能显示任务卡、来源文档、证据与治理、任务清单。
- worktree 分支领取任务后，运行态能显示分支、run 和 checklist。
- Follow-up 视图能展示 open、accepted、converted 等状态。
- 风险视角和协作健康检查没有结构性 warning。

## 真实项目接入前检查

迁入真实项目前，至少跑：

```bash
npm test
ganttmd validate .
ganttmd doctor .
```

在真实项目中，至少跑：

```bash
ganttmd doctor
ganttmd migrate
ganttmd validate
```

如果要接入 CI，使用方项目可以先只加：

```yaml
- name: Validate GanttMD
  run: ganttmd validate
```

## 回滚

工具更新回滚：

```bash
npm install -g ganttmd@<version>
```

项目数据迁移回滚：

1. 找到 `.ganttmd/.backup/<timestamp>/`。
2. 对照备份文件和当前文件。
3. 手动恢复需要回滚的文件。
4. 运行：

```bash
ganttmd doctor
ganttmd validate
```

不要直接删除 `.ganttmd/` 来回滚；它是任务状态真相源。
